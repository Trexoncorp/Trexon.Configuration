## Источники и приоритет

Без явно добавленных источников читается env процесса. `Override` не отключает этот default. Первый вызов `ReadFrom.*` заменяет default явным списком. Источники читаются в порядке регистрации; последний выигрывает. Overrides всегда имеют высший приоритет, независимо от места вызова в цепочке.

Обычная цепочка: `config.ReadFrom.DotEnv(".env", optional: true).ReadFrom.EnvironmentVariables().Override("APP_PORT", "9000")`. Итог: override → env → dotenv → инициализаторы свойств. Неверное значение победившего источника вызывает ошибку; fallback к нижнему источнику не выполняется.

Ключи сравниваются через `StringComparer.Ordinal`, с учётом регистра на всех платформах. Для автоматически созданных имён используйте верхний регистр. Неизвестные ключи игнорируются: общий env содержит множество чужих переменных. Два свойства одной группы не могут ссылаться на один ключ; разные зарегистрированные группы могут читать одинаковые ключи.

`InMemory(IReadOnlyDictionary<string, string>)` копирует словарь при регистрации. Null-значения не принимаются. Пути `DotEnv` преобразуются в абсолютные при добавлении источника относительно текущего рабочего каталога. Сам файл читается при загрузке. Файлы и env процесса не изменяются.

## Имена и классы

`ProjectName` → `PROJECT_NAME`, `APIPrefix` → `API_PREFIX`, `DbPoolSize` → `DB_POOL_SIZE`, `HTTP2Port` → `HTTP2_PORT`. Уже записанные подчёркивания сохраняются. Генерируемые имена и явные ключи должны соответствовать `[A-Za-z_][A-Za-z0-9_]*`.

`[Env("APP_HOST")]` задаёт полное имя ключа и обходит все префиксы. `[EnvPrefix("VAPID_")]` применяется к классу, на котором указан; префикс базового класса не наследуется. Суффикс `_` не добавляется автоматически. Пустой префикс допустим.

Публичные свойства базового класса загружаются вместе с остальными. Методы, static-свойства, индексаторы и неаннотированные read-only-свойства игнорируются. Если read-only-свойство помечено Env, Secret или валидатором, модель отклоняется.

Вложенные группы используют `__`. На каждом уровне добавляется префикс типа: root `[EnvPrefix("APP_")]` + `Database` + `[EnvPrefix("DB_")]` на вложенном типе даёт `APP_DATABASE__DB_POOL_SIZE`. Для простого `DATABASE__POOL_SIZE` префиксы не нужны. Env-alias допустим только на scalar-свойстве.

<!-- verify: ru-nested -->
```csharp
using Trexon.Configuration;

var settings = Settings.Load<AppSettings>(config => config
    .ReadFrom.InMemory(new Dictionary<string, string> { ["DATABASE__POOL_SIZE"] = "5" }));
if (settings.Database.PoolSize != 5) throw new Exception("Pool mismatch");

public sealed class AppSettings : CommonSettings
{
    public DatabaseSettings Database { get; init; } = new();
}
public abstract class CommonSettings
{
    public string ProjectName { get; init; } = "Widget iSpace";
}
public sealed class DatabaseSettings
{
    public int PoolSize { get; init; } = 3;
}
```

Инициализированная вложенная группа сохраняет собственные defaults. Null-группа создаётся только при наличии одного из её известных ключей. Иначе она остаётся null; для обязательной группы нужен `[Required]`.

Коллекции, словари, произвольные structs, interface/abstract-типы вложенных свойств и конструкторы с обязательными параметрами не поддерживаются. Циклы моделей запрещены, глубина ограничена 32 классами. Не используйте общие static-объекты как инициализаторы вложенных групп: загрузчик заполняет созданный моделью объект.

## Преобразование значений

| Тип | Формат |
| --- | --- |
| `string` | Исходная строка без преобразования |
| `bool` | `true`, `false` без учёта регистра; `1`, `0` |
| `byte/sbyte/short/ushort/int/uint/long/ulong` | Целое число, проверка диапазона |
| `float/double/decimal` | Invariant culture, точка, допустима экспонента; без разделителей групп |
| `float/double` | Только конечные значения, NaN/Infinity запрещены |
| enum | Только имя без учёта регистра; числа и комбинации flags не принимаются |
| `Guid` | Форматы, принимаемые `Guid.Parse` |
| `Uri` | Корректный абсолютный URI; относительные пути не принимаются |
| `TimeSpan` | Стандартный формат `c`: `00:00:00.2000000` |
| `DateTime`, `DateTimeOffset` | Round-trip `O`, включая 7 знаков долей секунды |
| `DateOnly` | `yyyy-MM-dd` |
| `TimeOnly` | `HH:mm:ss` с необязательными долями до 7 знаков |
| `Nullable<T>` | Те же форматы; пустая строка означает null |

Отсутствующий ключ сохраняет default. Пустая строка для `string` остаётся пустой; для ненулевого числового типа это ошибка. Строка `null` не имеет специального значения. `string?` не заменяет `[Required]`, и nullable-аннотации не проверяются автоматически.

## Поддерживаемый dotenv

UTF-8, BOM допустим. Поддерживаются пустые строки, комментарии `#`, `export KEY=value`, пробелы вокруг `=`, пустые значения, одинарные и двойные кавычки. Последнее повторение ключа в файле выигрывает.

```dotenv
APP_PORT=8080
PROJECT_NAME="Widget iSpace"
TOKEN='literal # text'
HOST=localhost # comment
VALUE=abc#literal
```

В значениях без кавычек inline-комментарий начинается с `#` в начале значения или после пробельного символа. После закрывающей кавычки разрешён только комментарий, отделённый пробелом. Одинарные кавычки сохраняют содержимое буквально. Двойные поддерживают `\n`, `\r`, `\t`, `\\`, `\"`; неизвестный escape — ошибка.

Интерполяция `${NAME}`, выполнение shell, multiline и продолжение строк не поддерживаются. `${NAME}` сохраняется буквально. Ошибка синтаксиса содержит номер строки без её содержимого. Некорректный UTF-8 вызывает ошибку кодировки без исходных данных; UTF-16/UTF-32 не поддерживаются. `optional: true` игнорирует только отсутствие файла/каталога, но не ошибки синтаксиса и доступа. Ошибка любого зарегистрированного источника останавливает загрузку, даже если его значения были бы перекрыты.
