# Границы версии 1.0

[Русский](ROADMAP.md) · [English](en/ROADMAP.md) · [Deutsch](de/ROADMAP.md)

[Оглавление](README.md)

Первая версия включает типизированные классы, defaults, env, dotenv, InMemory, overrides, aliases, префиксы, наследование, вложенные группы, явное преобразование scalar-типов, DataAnnotations, IValidatableObject, безопасные ошибки и независимые менеджеры.

Для сохранения простого API в 1.0 отсутствуют: автоматическая перезагрузка, file watchers, мутация ранее выданных объектов, DI/IOptions-адаптеры, JSON/YAML/XML-конфиги, CLI parsing, remote secret stores, коллекции и JSON внутри env, произвольные converters, собственные providers, dotenv interpolation, source generators и гарантии Native AOT.

Если понадобится новое значение, повторите `Settings.Load<T>` или создайте новый менеджер. Это не меняет объекты, которые уже получили потребители. Изменения env родительской shell не обновляют окружение уже запущенного процесса.

Следующие возможности добавляются по реальной потребности; обязательств по срокам нет. Выпуск `v1.0.0` ожидает отдельного разрешения владельца.
